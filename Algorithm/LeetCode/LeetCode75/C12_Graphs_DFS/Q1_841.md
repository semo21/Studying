# 841. Keys and Rooms

## Difficulty
- Medium

## Point
- Use DFS with a `stack`, starting from room `0`.
- Use `visited` to avoid visiting the same room twice.
- Iterating rooms by index does not work, because the visit order depends on the keys.

## Code
```c++
class Solution {
public:
    bool canVisitAllRooms(vector<vector<int>>& rooms) {
        vector<bool> visited(rooms.size(), false);        
        stack<int> st;
        
        st.push(0);

        while(!st.empty()){
            int cur = st.top();
            st.pop();

            if(visited[cur])    continue;            
            
            visited[cur] = true;
            for(int key : rooms[cur]){
                st.push(key);
            }
        }

        for(bool b : visited){
            if(b == false)  return false;
        }
        return true;        
    }
};
```

### Constraints
- n == rooms.length
- 2 <= n <= 1000
- 0 <= rooms[i].length <= 1000
- 1 <= sum(rooms[i].length) <= 3000
- 0 <= rooms[i][j] < n
- All the values of rooms[i] are unique.

## Explanation
- Create `visited` with size `rooms.size()`, all `false`.
- Push room `0` into the stack, because it is the only unlocked room.
- Traverse while the stack is not empty.
- Pop the top into `cur`.
- If `cur` is already visited, `continue`. The same room can be pushed several times by different keys.
- Otherwise set in `rooms[cur]` into the stack.
- After the traversal, if any room is still `false`, return `false`.
- Otherwise return `true`.

## Complexity
### Time Complexity: O(n + m)
- n is the number of rooms, m is the total number of keys.
- Each room is processed once because of `visited`.
- Each key is pushed and popped once.

### Space Complexity: O(n + m)
- `visited` stores n booleans.
- The stack can hold up to m room numbers.
